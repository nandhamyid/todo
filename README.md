# Todo App

A small, dependency-free todo app built with plain HTML, CSS, and JavaScript.

## Features

- Add, complete, edit (double-click), and delete tasks
- Filter by All, Active, or Done
- Clear all completed tasks
- Tasks are saved in your browser (`localStorage`)
- Keyboard accessible, responsive, and supports light and dark mode

## Run it

Open `index.html` in a browser. No build step or install needed.

## Put it on GitHub

```bash
git init
git add .
git commit -m "Add todo app"
git branch -M main
git remote add origin https://github.com/<your-username>/todo-app.git
git push -u origin main
```

To host it for free, open the repo on GitHub, go to **Settings → Pages**, and set the source to the `main` branch.
